# 업무도우미

티처데스크·쌤패스와 함께 쓰는 교사용 업무 도구함이에요. © 2026 Kang SeongHo. 비영리 공유를 허락해요(자세한 조건은 LICENSE).

## 구성
- **좁은 패널** (`index.html`): 화면 가장자리에 세워 두는 창이에요. 빠른 점검, Byte, 문구, 날짜 계산, 유콜 열기, 도구 목록이 있어요.
- **큰 작업 창** (`tools/`): 패널에서 누르면 따로 열려요.
  - `check.html` 일람표·PDF 점검, `seat.html` 자리뽑기
  - `docs.html` 문서 도구: 첨부 용량 맞추기(합계 5MB 기본), PDF 합치기·쪽 골라내기·돌리기, 한글·PDF·워드 읽기
  - `roster.html` 명단 도구: 미제출자 찾기, 이름 가리기, 학생별 문구
  - `grade.html` 수행평가 계산

## 개인정보
- 서버가 없어요. 도구에 넣은 파일, 명단, 점수는 브라우저 안에서만 처리하고 저장하지 않아요.
- 설정(유콜 주소, 용량 제한, 문구)은 각자 PC의 브라우저에만 저장돼요.
- 바깥으로 나가는 연결은 글꼴·라이브러리 CDN과 각자 넣은 유콜 화면뿐이에요.
- 이 저장소는 공개예요. 학생 정보, 유콜 주소·키를 절대 올리지 마세요.

## 업데이트하는 법 (관리자)
파일을 고친 뒤 `version.js`의 버전과 바뀐 점, `sw.js`의 `CACHE` 이름을 함께 올려요.

자리뽑기 사용 설명서

처음 쓰는 선생님도 순서대로 따라 하면 돼요. 버튼 이름은 이렇게 표시했어요.

1. 처음 시작하기 — 학생 명단 넣기

위쪽 명단을 누르면 명단 창이 열려요. 세 가지 방법 중 편한 것을 쓰세요.

  1. 명렬표 파일 그대로 넣기: 엑셀(.xlsx, .xls), 한글(.hwpx), PDF, CSV 파일을 끌어다 놓거나 파일 고르기를 눌러요. 학년 전체가 들어 있는 명렬표면 반 고르기에서 우리 반을 골라요.
  2. 표 복사해서 붙여넣기: 엑셀이나 한글에서 표를 드래그해 복사(Ctrl+C)한 뒤, 붙여넣기 칸에 붙여넣어요(Ctrl+V).
  3. 직접 입력하기: 이름을 적고 Enter를 누르면 번호가 자동으로 넘어가요. ‘홍길동 남’처럼 띄어 적으면 성별도 들어가요.

읽어 온 명단은 오른쪽 읽어 온 명단 확인에서 고친 뒤 이 명단 등록하기를 눌러요.

성별이 없는 명렬표라면 학생마다 남/여를 누르거나, “1~○번 남, 나머지 여”로 한꺼번에 정할 수 있어요. 남녀 구분이 필요 없으면 성별 안 넣기를 켜세요.
예전 한글 파일(.hwp)은 바로 읽을 수 없어요. 한글에서 PDF로 저장하거나 표를 복사해 붙여넣으세요.

2. 교실 대형 만들기

  1. 위쪽 분단 대형 / 모둠 대형 중 하나를 골라요.
  2. 대형을 눌러 분단 수, 한 책상 인원, 줄 수(모둠은 모둠 수와 모양)를 정해요.
  3. 쓰지 않는 자리(기둥, 사물함 앞 등)는 자리 오른쪽 위 ×를 눌러 비워 둬요.
  4. 남·여 자리를 정하고 싶으면 대형 창이 열린 상태에서 자리를 눌러요(남학생 자리 → 여학생 자리 → 구분 없음).
대형 창을 열지 않아도, 뽑기 전에 빈자리를 누르면 이 자리 비워 두기로 바로 비워 둘 수 있어요.

자리 번호는 앞줄 왼쪽부터 매겨져요. 학생을 넣고 빼도 번호는 그대로이고, 대형을 바꾸면 새로 매겨져요.

3. 자리 뽑기

  1. 필요하면 뽑기 설정에서 조건을 정해요.
    • 성별: 상관없음 / 자리에 정한 대로 / 같은 성별끼리 / 남녀 섞어서
    • 지난 기록 반영: 지난번 짝, 지난번 자리 피하기
    • 빈자리: 뒤쪽부터 / 아무 데나
    • 결과 보여 주는 방식: 한꺼번에 / 한 자리씩(스페이스바로 넘기기)
  2. 주황색 자리 뽑기를 누르면 큰 뽑기 화면이 열려요. TV·전자칠판에 띄우고 전체 화면을 누르면 좋아요.
  3. 뽑기 시작을 누르면 이름이 섞이다가 자리가 정해져요.
  4. 마음에 들면 이대로 확정, 다시 하려면 다시 뽑기를 눌러요. 확정해야 기록에 남아요.

4. 규칙 정하기

규칙에서 학생을 고른 뒤 규칙 버튼을 눌러요.

  • 서로 떨어뜨리기: 고른 학생들이 짝(모둠)이 되지 않게, 또는 앞뒤옆에도 앉지 않게 해요.
  • 앞자리에만: 앞에서 몇 줄 안에만 앉게 해요(시력, 집중 등).
  • 맨 뒷줄 금지, 혼자 앉지 않게
조건을 다 지킬 수 없을 때는 최대한 맞춘 결과를 보여 주고, 확정한 뒤 화면 위쪽에 지키지 못한 조건을 알려 줘요. 뽑기 화면에는 학생 이름이 나오지 않아요.

5. 자리 직접 바꾸기

  • 두 자리 바꾸기: 자리 하나를 누르고 다른 자리를 누르거나, 끌어다 놓아요.
  • 자리에서 빼기: 학생 자리에 마우스를 올리면 나오는 ×를 눌러요.
  • 빈자리에 앉히기: 빈자리를 누르면 자리 없는 학생 목록이 떠요.
  • 왼쪽 명렬표에서 끌기: 왼쪽 명렬표의 이름을 원하는 자리로 끌어다 놓아요. 이름을 누르면 그 학생 자리가 깜빡여요.

직접 바꾼 배치는 기록에 저장을 눌러야 기록에 남아요.

6. 자리 미리 정하기 (학생들 모르게)

  1. 더 보기 → 자리 미리 정하기를 눌러요.
  2. 자리를 누르거나 오른쪽 학생 이름을 끌어다 놓아 원하는 자리를 정해요. 일부 학생만 정해도 돼요.
  3. 다음 뽑기에 적용이 켜진 것을 확인하고 완료를 눌러요.
  4. 평소처럼 자리 뽑기를 하면, 이름이 섞이는 연출 뒤에 정해 둔 자리로 나와요. 나머지 학생은 규칙대로 무작위로 들어가요.
주의: 미리 정하기 창은 꼭 화면을 TV에 띄우기 전에 열어 주세요. 이대로 확정을 한 번 하면 적용이 자동으로 꺼져요.

7. 출력하기

  1. 출력을 누르면 출력 창이 열려요(처음엔 가로 용지).
  2. 종이에 넣을 것(자리표 · 명렬표 · 선생님이 남길 말)을 고르고, 남길 말을 적어요.
  3. 미리보기에서 칸을 끌어서 옮기고, 오른쪽 아래 주황색 모서리를 끌어 크기를 바꿔요.
  4. 인쇄하기 또는 그림 파일(PNG)로를 눌러요.
배치가 엉키면 처음 배치로 되돌리기를 누르세요. 교사 쪽에서 본 방향, 출석번호·자리 번호 표시는 자세한 설정에 있어요.

8. 저장하고 불러오기

  • 자동 저장: 명단, 대형, 배치는 이 컴퓨터의 크롬(브라우저)에 저장돼서 다시 열어도 그대로예요.
  • 자리 파일 저장 / 불러오기: 이번 배치만 파일로 보관했다가 다음에 그대로 불러와요.
  • 기록: 확정한 배치가 날짜별로 쌓여요. 불러오기도 되고, ‘지난 짝 피하기’에 쓰여요.
  • 전체 자료 백업: 더 보기 → 전체 자료 백업. 다른 컴퓨터로 옮길 때 이 파일을 가져가서 전체 자료 백업 불러오기를 해요.
인터넷 사용 기록이나 사이트 데이터를 지우면 자동 저장도 지워질 수 있어요. 학기 중간중간 전체 자료 백업을 해 두세요.

9. 전입생 · 전출생

  • 전입생: 명단 → 직접 입력하기에 이름을 적고 Enter. 마지막 다음 번호가 자동으로 들어가요. 중간 번호를 적으면 뒤 학생 번호를 미룰지 물어봐요. 들어온 학생은 ‘자리 없는 학생’에 나오니 빈자리를 눌러 앉히세요.
  • 전출생: 지금 명단에서 이름 옆 ×. 뒤 번호를 당길지 물어보는데, 번호를 비워 두는 학교라면 그대로 두기를 고르세요. 앉아 있던 자리는 빈자리가 돼요.

10. 초기화

빨간 초기화를 누르면 세 가지 중에서 골라요.

  • 자리 배치만 비우기: 앉은 학생만 빼요.
  • 교실을 처음 상태로: 배치, 비워 둔 자리, 남·여 자리, 미리 정한 자리를 지워요. 명단과 기록은 남아요.
  • 모든 자료 지우기: 전부 지워요. 되돌릴 수 없으니 먼저 백업하세요.

11. 자주 묻는 질문

학생 정보가 인터넷으로 나가나요?
아니요. 명단은 이 컴퓨터의 브라우저에만 저장돼요. 파일 읽기와 글꼴을 위해 인터넷에서 프로그램 조각만 받아 와요.
인터넷이 없으면요?
자리 뽑기, 직접 입력, 붙여넣기, 인쇄는 돼요. 엑셀·한글·PDF 파일 읽기와 그림 파일 저장은 인터넷이 필요해요.
다른 선생님께 드려도 되나요?
이 HTML 파일 하나만 드리면 돼요. 명단은 파일 안에 들어 있지 않아서 각자 컴퓨터에서 새로 넣어 써요.
화면이 작게 보여요.
왼쪽 명렬표를 ‹로 접거나, 크게 보기를 쓰세요. 성별 색·출석번호·자리 번호 표시는 뽑기 설정에서 바꿀 수 있어요.

자리 미리 정하기

여기서 정한 자리는 평소 화면에 드러나지 않아요. 다음 자리 뽑기에서 이름이 섞이는 연출 뒤에 이 자리로 나와요. 정하지 않은 학생은 규칙에 맞춰 무작위로 들어가요.

자리를 누르면 여기 학생 중에서 고를 수 있어요. 이름을 자리로 끌어다 놓아도 돼요.

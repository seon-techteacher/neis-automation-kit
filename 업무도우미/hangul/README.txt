[설치 파일 하나로 쓰기 (압축 풀기 없음)]
- 업무도우미 '시험지 점검' 화면의 '설치 파일 받기'로 '시험지 편집 도우미 설치.cmd'를 받아 두 번 누릅니다.
- 'Windows의 PC 보호' 창이 뜨면 '추가 정보' → '실행'을 누르세요. 관리자 권한은 필요 없어요.
- 바탕화면에 '시험지 편집 도우미' 바로가기가 생기고, 업무도우미 패널 버튼과도 연결돼요.
- 새 판이 나오면 설치 파일을 다시 받아 실행하고 '예'를 누르면 바뀌어요. 지우려면 다시 실행해 '아니요(지우기)'.
- 설치 위치: %LOCALAPPDATA%\udesk\exam-helper
- 아래는 압축 파일로 받아 직접 풀어 쓰는 방법이에요.

[여는 법]
1. 한글에서 시험지(원안지 양식으로 만든 문서)를 엽니다.
2. 이 폴더의 '시험지 편집 도우미 열기.cmd'를 두 번 누릅니다.
3. 화면 오른쪽에 버튼 창이 뜹니다. 항상 위에 떠 있고, 눌러도 한글의 커서·선택이 그대로 남아요.

[업무도우미 패널 버튼으로 열기]
- 이 PC에서 처음 한 번 '편집 도우미 버튼 연결.cmd'를 두 번 누르세요. 그 뒤에는 업무도우미 패널의
  '시험지 편집 도우미' 버튼이나 시험지 점검 화면의 '편집 도우미 열기'로 창이 열려요.
- 처음 누를 때 브라우저가 "이 사이트에서 앱을 열까요?"라고 물으면 '항상 허용'에 표시하고 '열기'를 누르세요.
- 업무도우미 폴더를 다른 곳으로 옮기면 연결.cmd를 다시 실행하세요. 없애려면 '편집 도우미 버튼 연결 해제.cmd'.

[쓰는 법]
- 글자 · 줄: 한글에서 글자를 드래그한 뒤 누르세요. (자간 좁게 = Shift+Alt+N)
- 문항 서식: 커서가 있는 문단에 적용돼요.
  발문(번호 자동) = Ctrl+2, 선택지 = Ctrl+3, <보기> 안 글 = Ctrl+5, 바탕글 = Ctrl+1 (학교 원안지 양식의 스타일)
  여기서 줄 맞추기 = Shift+Tab (맞출 글자 앞에 커서를 두고)
  부정어 밑줄: 발문에서 '않은·않는·아닌·없는·틀린·다른 것' 등을 찾아 밑줄
  배점 넣기: −/+로 점수를 고른 뒤 누르면 문단 끝에 【3.5점】
- 상자 넣기: 기출에서 떼어 온 <보기> 상자, 지문 상자를 커서 아래에 넣어요.
- 선택지: ①~⑤ 줄만 드래그한 뒤 '짧은 것부터 ①'. 바뀐 정답 번호가 창 아래에 나와요.
  출제 요령대로 놓아요: 'ㄱ, ㄴ' 같은 기호 묶음은 개수가 적은 것부터(같으면 가나다),
  'A는…', 'B와 C는…'처럼 A·B·C로 시작하면 하나짜리를 A→B→C 차례로 먼저, 그 밖은 짧은 것→긴 것(같으면 가나다).
- 묶음 지시문 '[ ~ ] 다음 글을 읽고 물음에 답하시오.', 출처 '- 「」 -', 기호 ○ 『』 「」 “” ‘’ 버튼도 있어요.
  글자 모양(밑줄 등)은 첫 글자 모양으로 맞춰지니, 밑줄 있는 선택지는 확인하세요.
- 잘못 눌렀으면 '되돌리기'(Ctrl+Z).
